# Carlos Olivares Croc

**Embedded Systems & IoT Specialist**  
Viña del Mar, Chile · [LinkedIn](https://www.linkedin.com/in/olivarescroc/)

I develop and integrate embedded and IoT systems, connecting field sensors, firmware, industrial communications and cloud applications. My experience spans water monitoring, agricultural systems, energy and vehicle electronics.

My focus is reliable telemetry and remote asset monitoring, supported by hardware–software integration, technical documentation, and validation in the lab and in the field.

## Areas of work

- **Embedded firmware:** C/C++ development, sensor acquisition, device diagnostics and local data persistence.
- **Industrial communications:** integration of Modbus RTU/RS485, CAN/J1939 and MQTT/TLS across devices and telemetry services.
- **Remote monitoring:** sensor integration and communications for water, pressure, soil and weather monitoring.
- **IoT integration:** Python services, data bridges and cloud connectivity, including work on AWS IoT pilot architectures.
